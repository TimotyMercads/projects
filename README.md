## Projects in this repo

### [Snake-Game](./Snake-Game)
**Hand-gesture-controlled classic game**
Classic Snake game where movement is controlled entirely through a trained hand-gesture recognition model via webcam.
**Tech:** Python, Machine Learning, Computer Vision

### [Inspirational-Quote-App](./Inspirational-Quote-App)
**Mobile app — Android Studio / Flutter / Dart**
Displays a randomized inspirational quote on each button press, with a favorites system to save and revisit preferred quotes.
**Tech:** Flutter, Dart, Android Studio

### [Valber-Shop](./Valber-Shop)
**Lexicon-based sentiment analysis system**
Sentiment analysis system for barbershop product and service reviews using a lexicon-integration algorithm; users can submit, edit, and delete reviews. Backend developer on this project — built sentiment analysis logic, review fetching, pagination, and activity logging.
**Tech:** Python, Sentiment Analysis (Lexicon-based), backend/database integration

### [Thesis-App](./Thesis-App)
**Predicting At-Risk and High-Performing Students** *(Thesis Project)*
Implementation and evaluation of a supervised ML model with explainability features to identify at-risk vs. high-performing students. Built as a Flask web app with a MySQL database.
**Tech:** Python, Flask, HTML, JavaScript, MySQL/XAMPP

### [Inventory-System](./Inventory-System)
**Band Instrument Rental Inventory System**
Tracks which band instruments are available for rent vs. currently rented, including rental duration and due dates. Backend developer on a small team.
**Tech:** Backend development (team project)

### [TLC-Haircut-Advisor](./TLC-Haircut-Advisor)
**Face-shape haircut advisor web app (client project: TLC Barbershop)**
Mobile-first web app that finds your face shape from your camera using MediaPipe Face Landmarker, entirely in the browser (no uploads, no backend), then suggests suited haircuts and previews them on your face. Group project (PTF50, Angeles University Foundation).
**Tech:** HTML, CSS, JavaScript, MediaPipe Face Landmarker, Vercel

### AlignMate *(coming soon)*
**Computer-vision posture corrector**
Uses a pre-trained machine learning model with live webcam input to detect and correct poor posture while sitting or standing.
**Tech:** Python, Machine Learning (pre-trained model), OpenCV/webcam input
